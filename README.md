# Catch the Time v3.0

A local-only Android app that notifies you when the 24-hour clock lands on a satisfying catch-time moment.

## v3.0

- Refined hand-catching-clock launcher mark and matching in-app identity.
- Cleaner Now screen with notification system status moved to the bottom.
- Four selectable typography profiles: Clean, Neo, Retro and Classic.
- Device-local palette presets including Pocket and Neon, plus full custom colours.
- Curated time pattern packs, custom times, copy/share, widgets, notification styles and setup transfer.
- Setup export upgraded to CTT3 and remains backwards-compatible with CTT2 imports.
- No Internet permission, accounts, analytics, ads or cloud dependency.

## Build

The included GitHub Actions workflow builds a debug APK on every push to `main`.
